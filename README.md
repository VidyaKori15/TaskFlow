# TaskFlow | Plan. Organize. Accomplish.

TaskFlow is a modern, professional Task Management web application designed to help users organize their daily workflow efficiently. It features a clean SaaS-style dashboard, Kanban board, and productivity analytics.

## 🚀 Live Demo
[View TaskFlow Live](https://vidyakori15.github.io/TaskFlow/) 


## ✨ Key Features
- **Dashboard Statistics:** Real-time updates for total, in-progress, and overdue tasks.
- **Three Core Views:** Switch between List View, Kanban Board, and Monthly Calendar.
- **Productivity Tracking:** Visual progress bars based on task completion.
- **Dark Mode:** Fully responsive dark and light theme toggle.
- **LocalStorage:** All data is saved locally in the browser (no backend required).
- **Categorization:** Create custom lists for Work, Study, or Personal projects.

## 🛠️ Tech Stack
- **Languages:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Framework:** Bootstrap 5
- **Icons:** Font Awesome 6
- **Storage:** Browser LocalStorage API
